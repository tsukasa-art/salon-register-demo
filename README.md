# サロンPOS ワークフローデモ

[English](README.en.md)

小規模な美容室・サロンの**受付から会計、締め作業までの業務フロー**を、
ブラウザ上で一通り確認できる公開用デモです。

実運用環境とは分離し、バックエンドや実在する顧客情報を使用せず、サンプルのメニュー・商品データと
ブラウザ内のIndexedDB / localStorageだけで動作します。UIはモバイルファーストで設計し、
店頭のスマートフォン、タブレット、デスクトップを想定しています。

**[ブラウザでデモを開く →](https://salon-register-demo.pages.dev/)**

## 確認できる業務フロー

1. **受付・顧客追加** — 複数の顧客を追加し、施術内容を顧客ごとに管理
2. **メニュー・商品選択** — 施術メニュー、店販商品、価格・割引設定を明細へ反映
3. **会計** — 個別会計またはまとめて会計、お預かり金額とお釣りを確認
4. **履歴管理** — 会計結果をIndexedDBへ保存し、過去1週間の履歴を表示
5. **締め作業** — 売上合計、平均単価、商品別TOP5、ピーク時間帯を集計
6. **データ管理** — 会計履歴をJSONでバックアップ・復元

## 実装上のポイント

| 領域 | 実装 |
|---|---|
| UI | Vite + Vanilla JavaScript。画面と機能を`src/modules/`へ分割 |
| 型のあるデータ層 | TypeScriptで会計履歴、メニュー・商品、カテゴリを定義 |
| ローカル永続化 | 会計履歴はIndexedDB、設定と商品はlocalStorageへ保存 |
| レスポンシブ | モバイルファースト。タブレット・デスクトップ幅にも対応 |
| 操作性 | Enter / Esc / 検索フォーカス / 金額入力のキーボードショートカット |
| オフライン対応 | Web App ManifestとService Workerをproduction buildで登録 |

### 公開デモとしての境界

- 認証画面は操作フローを確認するためのもので、サーバー認証は行いません。
- メニューと商品はリポジトリ内のサンプルJSONを使用します。
- 会計履歴や設定は利用中のブラウザだけに保存され、外部サーバーへ送信しません。
- 実運用で必要になる権限管理、サーバー同期、決済端末連携、監査logは対象外です。

## 主な機能

- **レジ操作**  
  複数顧客、メニュー／商品選択、合計・お預かり・お釣り、会計確定。  
  複数顧客時は「個別会計」「まとめて会計」を選択できます。
- **価格・割引設定**  
  カラー時／パーマ時のカット料金と、施術メニューの価格を変更できます。
- **商品管理**  
  商品の追加、価格変更、削除に対応します。
- **テーマ設定**  
  色プリセットの選択と、カスタムプリセットの保存・削除ができます。
- **会計データ管理**  
  IndexedDBの会計履歴をJSONでバックアップ・復元できます。
- **締め作業**  
  日次レポート、商品別TOP5、ピーク時間帯、過去1週間の履歴を確認できます。

## デモの操作

1. [公開デモ](https://salon-register-demo.pages.dev/)を開く
2. 「デモで始める」を押す
3. メニューまたは商品を選び、明細へ追加する
4. 必要に応じて顧客を追加し、個別会計またはまとめて会計を選ぶ
5. ハンバーガーメニューから締め作業、料金設定、テーマ、データ管理を確認する

キーボードではEnter（会計）、Esc（モーダルを閉じる）、`/`（商品検索）、
`0`–`9`（クイック金額）を利用できます。

## ローカルで実行

```bash
pnpm install
pnpm run dev
```

表示されたURLで`/login.html`を開きます。

## ビルド

```bash
pnpm run build
```

静的ファイルが`dist/`へ出力されます。
